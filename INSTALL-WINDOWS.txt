About the Setup.exe
-------------------
This is a standard Inno Setup 6 installer. It installs into your OBS Studio
folder (default C:\Program Files\obs-studio):

  <OBS>\obs-plugins\64bit\obs-shorts-vertical.dll
  <OBS>\data\obs-plugins\obs-shorts-vertical\

Administrator rights (UAC) are required. Setup detects OBS automatically; if
OBS is not found you can browse to the folder that contains bin\64bit\obs64.exe.

Requires OBS Studio 32.0 or newer (64-bit). Vertical Shorts 1.0.6 could show
"Plugin Load Error" on OBS 32.0/32.1 because it advertised module API 32.2;
1.0.7 fixes that. If the plugin still fails to load, open:
  Help → Log Files → View Current Log
and look for lines containing [obs-shorts-vertical] or
"incompatible version" / "Module '...' not loaded".

Local filename (exact):

  Vertical-Shorts-Plugin-1.0.7-Setup.exe

Install log (written on every run):

  %LOCALAPPDATA%\VerticalShortsPlugin\logs\install-*.log

Authenticode:
  When signing credentials are configured in CI, production releases are
  Authenticode-signed. Verify with:
    Get-AuthenticodeSignature "Vertical-Shorts-Plugin-1.0.7-Setup.exe"
  Status should be Valid when signed.

Do NOT disable Windows Defender.

Requirements

- No Visual Studio / CMake / Git required on the target PC

Upgrading from a previous version
---------------------------------
You do not need to uninstall first.

1. Download the newer "Vertical-Shorts-Plugin-<version>-Setup.exe".
2. Run it. If an older build is detected, choose Upgrade (or Cancel).
3. If OBS is open (or the plugin DLL is locked), close OBS and click Retry.
   Setup will not replace the plugin DLL while OBS has it loaded, and will
   not force-kill OBS.
4. Finish the wizard. Your destinations, credentials, vertical scenes/sources,
   schedules, and other settings are preserved. No computer restart is required.

The AppId stays the same across every Vertical Shorts Plugin version so Windows
treats each Setup.exe as an upgrade of the same product.

Install with Setup.exe (recommended)
------------------------------------
1. Close OBS Studio completely.
2. Run "Vertical-Shorts-Plugin-1.0.7-Setup.exe", approve UAC, confirm the OBS
   folder (usually C:\Program Files\obs-studio), and finish the wizard.
3. Start OBS Studio.
4. If OBS shows Tools → Plugin Manager, ensure "Vertical Shorts Plugin" is enabled,
   then restart OBS if you just enabled it.
5. Open View → Docks → Vertical Shorts
   (also Tools → Vertical Shorts).
6. Confirm the main OBS canvas remains unchanged while editing the separate vertical composition.
7. Test Vertical Go Live, Vertical Record, Short Clip, Long Clip, and Settings.
8. Confirm output files save to the selected vertical recording path.

Install from zip
----------------
1. Close OBS Studio completely.
2. Locate your OBS install folder (usually C:\Program Files\obs-studio).
3. Copy:

   zip\obs-shorts-vertical\bin\64bit\obs-shorts-vertical.dll
     → <OBS>\obs-plugins\64bit\obs-shorts-vertical.dll

   zip\obs-shorts-vertical\data\*
     → <OBS>\data\obs-plugins\obs-shorts-vertical\

4. Start OBS Studio and open View → Docks → Vertical Shorts.

Troubleshooting
---------------
- "OBS Studio could not be found" / invalid folder:
  Browse to the folder that contains bin\64bit\obs64.exe.
- "OBS Studio must be closed" / Retry:
  Fully quit OBS (check the system tray), then Retry.
- "Administrator permission is required":
  Approve the UAC prompt; OBS is normally under Program Files.
- Install failed and you need details:
  Open %LOCALAPPDATA%\VerticalShortsPlugin\logs\ and read the newest install-*.log

Uninstall
---------
Use Windows Apps & features → Vertical Shorts Plugin.
Your OBS scene collections and Credential Manager secrets are left intact.
